## Deploy to Vercel — easiest method
1. Create/sign into GitHub.
2. Create a new repository, e.g. `saeed-niloufar-wedding`.
3. Upload ALL files and folders from this project (not the ZIP itself).
4. Open Vercel and sign in with GitHub.
5. Click Add New → Project.
6. Select the GitHub repository.
7. For this static project, leave the default settings; there is no build command.
8. Click Deploy.
9. Vercel will give you a live `.vercel.app` URL.

After that, every new push to the connected GitHub repository can trigger a new deployment.
